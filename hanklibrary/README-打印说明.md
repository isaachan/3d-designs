# Hank's Library 五色牌匾

## 当前模型

- 成品尺寸：240 × 50 × 3 mm
- 底板：2.4 mm
- 五色面层：0.6 mm（0.2 mm 层高时为 3 层）
- 圆角：3 mm
- 背面：完整平面，适合多块 3M 双面胶
- 颜色：深蓝、白、黑、红、黄
- EN 图案实际占 240 × 48.976 mm，上下居中
- CN 图案实际占 239.895 × 50 mm，左右居中

每种语言目录中有五个共用坐标系的 STL。深蓝 STL 同时包含整块底板和蓝色面层；另外四个 STL 位于 2.4–3.0 mm 高度。

## 在 Bambu Studio 中组合

以 EN 为例：

1. 打开 Bambu Studio，新建项目并选择正确的打印机、打印板和 0.4 mm 喷嘴。
2. 同时选中 `generated/EN` 目录内的五个 STL，并一次性拖入 Bambu Studio。
3. 出现“是否将这些文件作为一个包含多个零件的对象载入”时，选择“是”。不要分别导入和自动排列。
4. 在对象列表中展开牌匾，按文件名映射 AMS：
   - `blue` → 深蓝
   - `white` → 白
   - `black` → 黑
   - `red` → 红
   - `yellow` → 黄
5. 确认组合后的包围盒是 240 × 50 × 3 mm，且背面 Z=0 平放在打印板上。
6. 切片后重点查看 2.4–3.0 mm 的最后三层，确认五种颜色都出现，文字没有被当作独立漂浮对象移动。
7. 保存 Bambu Studio 工程为 3MF；CN 重复同样步骤。

## 建议切片参数

- PLA
- 0.4 mm 喷嘴
- 0.20 mm 层高
- Arachne 墙生成器
- 3 道墙
- 5 层底面、5 层顶面
- 15% Gyroid 填充
- 开启擦料塔
- 首版先关闭顶部熨平；确认颜色边界后再按喜好开启
- 牌匾正面朝上，无需支撑

底板前 12 层只有深蓝，最后 3 层才需要多色换料，因此比整块逐层五色打印节省耗材。

## 首次打印检查

1. 在切片预览中逐层查看细小雪花、边框和猫头鹰轮廓。低于喷嘴可制造宽度的装饰允许由切片器省略，但文字主体不应缺笔。
2. 确认打印板有效范围能容纳 240 mm 宽模型，并保留擦料塔空间。
3. 若深色污染白色，增加白色耗材的冲刷体积；必要时让白色多冲刷到模型填充中。
4. 打印完成后等待冷却再取件，减少 240 mm 长底板弯曲。
5. 粘贴前用异丙醇清洁牌匾背面和墙面，使用多条短 3M 胶均匀分布在四角与中部。

## 重新生成

双击 `rebuild.command`，或在终端运行：

```bash
cd /Users/kai.han/code/3d-designs/hanklibrary
./rebuild.command
```

直接调整参数的例子：

```bash
.venv/bin/python generate_plaques.py \
  --width 240 \
  --height 50 \
  --base-thickness 2.4 \
  --face-thickness 0.6 \
  --corner-radius 3
```

输出目录：

- `generated/EN`
- `generated/CN`
- `generated/build-report.json`
