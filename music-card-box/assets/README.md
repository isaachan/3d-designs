# 固定输入

- `design.json`：用户提供的卡片尺寸、设计余量、配色、零件角色与贴胶参考区域；首版 r1。
- `reference/cards.jpg`：用户提供的卡片照片，仅作外形和取放场景参考，不据此推算厚度、重量或张数。
- `print-profiles/`：写入主体 brim 时冻结的 X2D / 标准 0.4 mm / PLA 配置；来源于 garage-bookshelf 已解析的本机官方预设副本。主体工艺调整为外侧 brim 5 mm、15% 填充，颜色沿用本设计。原预设来源哈希保存在 `profile-sources.json`。
- `print-layout.json`：当前装饰排盘中心及 6 mm 扩边检查包络，使各色文件与主体的热床占位互不重叠；不改变装配几何。

生成工具只读取这些文件，不覆盖固定输入。尺寸和配色变更须更新修订、设计文档和验证记录。
