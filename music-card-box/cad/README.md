# 正式 CAD

唯一原生总装：[music-card-box-r1.FCStd](music-card-box-r1.FCStd)。包含全部六个实体及其原生草图和特征，颜色已保存。部件按[主体](main/README.md)与[装饰](decorations/README.md)分类，不复制多份可编辑模型。

[STEP 总装](music-card-box-r1.step)用于其他 CAD 软件交换；[model-spec.json](model-spec.json)定义角色和输入来源。STL 与通用 3MF 属于派生打印几何，见[打印入口](../printing/README.md)。
