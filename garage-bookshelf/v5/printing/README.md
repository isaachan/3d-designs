# 打印文件与组件选型

这里按产品组件保存当前使用的文件，不再设置current或按日期划分的交付目录。首次制作按以下顺序选择：

1. [主体](main/README.md)：14盘共40件，每盘打印一次。
2. [广告牌文字载板](sign-carriers/README.md)：上方、右侧各选一款。默认款共2盘、2件。
3. [车位卡槽](parking-inserts/README.md)：按车型和数量选配；现有车型件仍是待完成统一试配的候选件。

主体＋两块默认载板共16盘、42个打印件，另需4颗M3×8螺钉和4个M3螺母。车型卡槽另计。盘号保留原标识，不要求分类后连续编号；一盘可包含多件。

默认文件来自已有检查过的基线及连接片补充件；目录整理没有改变3MF。个人设置另列在各组件中，尤其手工修改的03盘仍保留，已有打印可继续使用对应个人文件。不要把个人设置与默认文件重复打印成两套。
