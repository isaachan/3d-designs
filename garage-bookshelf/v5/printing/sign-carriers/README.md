# 广告牌文字可换载板

上方和右侧各选一款，每款一件。固定广告牌和牌座已包含在[主体](../main/README.md)内。

| 位置 | 默认文件 | 个人设置 |
|---|---|---|
| 上方 | [10-top-carrier](upper/default/10-top-carrier-mpower.3mf) | [保留的个人文件](upper/personal/10-top-carrier-mpower.3mf) |
| 右侧 | [12-side-cartridge](side/default/12-side-cartridge-mpower.3mf) | [保留的个人文件](side/personal/12-side-cartridge-mpower.3mf) |

个人文件保留原字节，未因本次整理重新切片。已有打印继续使用原设置时选个人文件；首次制作使用默认文件。每个位置只选一个版本。

新增款放`upper/<款式>/`或`side/<款式>/`，附原生CAD来源、接口版本、打印设置及试装状态。两种接口不能互换，具体要求见[载板规范](../../docs/interfaces/sign-carriers.md)。
