# Mazda MX-5 车型托座候选件

[人工设置3MF](enchery-1-65-mazda-mx5-parking-tray-preview.3mf)只含一个托座，不含层板或车模。该文件保持人工设置原样：X2D、0.4mm、黑色PLA、0.20mm、2圈墙、15%填充、5mm brim、无支撑。

原有单件重开切片记录约15分钟、7.4g，几何与原预览托座一致；[原人工设置记录](../../../archive/printing/hand-edited-projects/enchery-1-65-mazda-mx5-parking-tray-preview.json)按原样归档。[源CAD与原预览研究](../../../studies/enchery-mx5-tray-2026-10-29/README.md)保留估算的轮胎位置，尚未实物试配。

该人工设置与新规范的4圈墙、25%填充、4mm brim不同，且没有最终件的两对象试配记录；当前属于保留候选，须按[指定方法](../../../docs/interfaces/parking-inserts.md)重新生成试配项目并记录验证后再确认。
