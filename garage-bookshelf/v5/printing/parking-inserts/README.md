# 车位卡槽选型

卡槽是可取放的车型托座；主体上的固定凹槽属于主体。每辆车选择对应款式，数量按实际车位配置，不把整个车型库计入一套整机。

| 款式 | 文件与说明 | 当前状态 |
|---|---|---|
| Mazda MX-5 | [款式说明](mazda-mx5/README.md) | 保留人工设置的预览件；轮胎位置为估算，未实物试配 |
| BMW Z4 E89 | [款式说明](bmw-z4-e89/README.md) | B28底脚已获无字版尺寸反馈；0.4mm凸字版未打印 |

这两款保留原打印文件，尚缺按统一规范完成的最终车型“层板＋托座”两对象试配记录，先作为候选件使用。不能把已有单件切片或几何检查当作全部规范已通过。

通用底脚没有车型轮胎夹。需要测试通用底脚接口时使用[指定试件目录](../../studies/parking-tray-fit-2026-10-26/README.md)中的层板＋底脚项目；其中层板是试配对象，不要额外算作车型卡槽交付件。

新增车型必须完整遵循[车型卡槽规范](../../docs/interfaces/parking-inserts.md)。
