# 车位卡槽选型

卡槽是带通用底脚、取放耳和四个弧形轮槽的可取放车型托座；主体上的固定凹槽属于主体。每辆车选择对应款式，数量按实际车位配置，不把整个车型库计入一套整机。

| 款式 | 文件与说明 | 当前状态 |
|---|---|---|
| BMW Z4 E89 | [款式说明](bmw-z4-e89/README.md) | 实测B28无字版尺寸已确认；当前0.4mm凸字版未打印 |

所有新增车型必须采用[BMW Z4 E89的设计方法](../../docs/interfaces/parking-inserts.md)，使用该车型自己的轮胎实测值，不凭外观估算轮心，也不直接套用参考车尺寸。

车型打印项目为单托座、单对象、单盘，不含层板或车模。通用底脚样件没有车型轮槽，不能当作已适配某车型的卡槽。几何与切片检查范围、无字版和加字版的实物状态分别记录。
