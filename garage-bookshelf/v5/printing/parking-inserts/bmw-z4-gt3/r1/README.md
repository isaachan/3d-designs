# BMW Z4 GT3 · r1 停车卡槽

卡槽采用 `parking-base-v1` 接口，含四个弧形轮槽、取放耳和 0.4 mm 高的 **BMW Z4 GT3** 凸字。总尺寸为 40 × 83 × 3.6 mm。[单件 3MF](bmw-z4-gt3-r1.3mf) · [可编辑 FreeCAD 模型](../../../../cad/parking-inserts/bmw-z4-gt3/r1/bmw-z4-gt3-r1.FCStd) · [预览](tray-preview.png)

| 参数 | 建模值（mm） |
|---|---:|
| 同侧前后轮外缘跨度 S | 48 |
| 前／后轴轮胎外侧总宽 Bf / Br | 30.5 / 30.9 |
| 前／后胎直径 Df / Dr | 10.8 / 10.8 |
| 前／后胎宽 Tf / Tr | 4 / 4 |

轴距为 37.2 mm，前轮距为 26.5 mm，后轮距为 26.9 mm，前后槽内宽均为 4.4 mm。[原始图片](../../../../assets/measurements/parking-insert-bmw-z4-gt3-2026-11-18.jpg) · [参数文件](../../../../cad/parking-inserts/bmw-z4-gt3/r1/measurements.json)

3MF 预设为 X2D、0.4 mm 喷嘴、黑色 PLA、0.20 mm 层高、4 圈墙、25% 填充，底板平放。重开切片为一盘一对象，约 16.4 分钟、7.64 g，切片结果无模型警告。[切片结果](slice-result.json) · [原始日志](evidence/slice.log)

CAD 重开重算、参数修改与恢复、理论轮胎净空、十车位干涉和网格检查均通过。车身和底盘的实际净空仍待试配确认。[验证报告](validation.json)
