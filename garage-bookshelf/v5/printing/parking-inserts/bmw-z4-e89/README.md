# BMW Z4 E89 车型卡槽 · 设计参考

[单件3MF](parking-tray-s51-b23-d10-t5p1.3mf)只含一个托座，实际参数为S51、B28、D10、T5.1，含0.4mm高BMW Z4 E89凸字。文件名b23是保留的旧路径，不代表当前宽度。

本款采用实测轮胎数据推导轮心、四个原生弧形轮槽和通用底脚，作为所有新增车型的[设计方法参考](../../../docs/interfaces/parking-inserts.md)。

打印设置为X2D、0.4mm、黑色PLA、0.20mm、4圈墙、25%填充、4mm自动brim、无支撑，底脚平放；既有单件切片估算约16分钟、7.7g。

已完成原生参数重算及往返、四轮理论净空、通用底脚双向比较、十个车位干涉、封闭网格和保存后单对象重开切片检查，详见[源CAD、测量定义和原始验证](../../../studies/measured-tray-s51-b23-d10-t5p1/README.md)。用户已确认无字B28版尺寸合适；当前0.4mm凸字版尚未打印，未验证碰撞载荷或防倾倒能力。
