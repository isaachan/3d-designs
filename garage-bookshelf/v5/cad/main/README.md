# 主体CAD

主体的正式源为[总装CAD](../garage-bookshelf-v5-assembly.FCStd)，本目录按组件提供入口，不复制第二份总装。

主体包含`module_1/2/3`、`garage_deck_1/2/3`、16个`column_*`、`billboard`、`side_receiver`、12个`book_skin_*`及4个`reinforcement_*`，共40个打印件。`billboard`是上方广告牌和支架，`side_receiver`是右侧固定牌座；两个对象属于不带可换文字的主体。

默认`top_carrier`和`side_cartridge`归[文字载板](../sign-carriers/README.md)，`parking_tray_interface`是[通用底脚样件](../parking-inserts/README.md)，不算主体打印件。外购M3硬件单独采购。
