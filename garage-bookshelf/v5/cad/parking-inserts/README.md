# 车位卡槽CAD

通用接口来自[正式总装](../garage-bookshelf-v5-assembly.FCStd)的`parking_tray_interface_Body`，只含底脚和取放耳，尚无车型固定结构。所有车型必须遵守[卡槽规范](../../docs/interfaces/parking-inserts.md)。

| 款式 | 当前唯一可编辑源 | 当前状态 |
|---|---|---|
| ENCHERY Mazda MX-5 | [研究CAD](../../studies/enchery-mx5-tray-2026-10-29/enchery-1-65-mazda-mx5-parking-tray-preview.FCStd) | 轮胎位置为视觉估算，未实物试配 |
| BMW Z4 E89 | [研究CAD](../../studies/measured-tray-s51-b23-d10-t5p1/parking-tray-s51-b23-d10-t5p1.FCStd) | 实际参数为B28；目录名b23是旧路径，当前0.4mm凸字版未打印 |

为保留生成脚本和原始证据，这两款源文件继续保存在对应研究目录，本索引不复制可编辑CAD。新增款放本目录`<车型>/<修订>/`，记录接口版本和源文件归属，再把最终件交给指定的层板＋托座验证流程。

两款既有研究检查均不能自动代替新规范要求的最终车型两对象试配。单件打印文件见[卡槽选型](../../printing/parking-inserts/README.md)。
