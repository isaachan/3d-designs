# 工具流程检查

在v5中运行：

```sh
python3 -m unittest discover -s tests -v
python3 tools/verify_printing.py
```

工具测试覆盖：生成结果只能进入build、不能覆盖既有结果或人工目录；拒绝过期／改动／越界文件；整机排盘覆盖全部零件；打包把40个主体零件与两块文字载板分开，拒绝不完整交付且不改当前打印文件；保存的通用接口试件保持真实尺寸与两个对象；实际定制载板CAD保持单一原生Body、正确文字及对应Pad/Pocket，保存3MF保持各位置的底色和白字。

车型工具的回归测试另外覆盖：非法车型／修订标识在加载CAD前被拒绝，绝对路径、目录穿越、符号链接越界及既有输出不会被写入；校验工具拒绝CAD、测量值、原始图片、冻结字形、原始日志或报告不匹配，以及缺失修订、过期总装哈希和错误的切片结果。已交付车型及旧BMW参考件的验证格式均纳入检查。

`verify_printing.py`只读检查当前组件清单、3MF覆盖、文件哈希、历史来源及零件角色；车型分支同时核对CAD、实测输入、原始来源、冻结字形与逐款验证记录的对应关系。不重新执行CAD、切片或实物验证。
