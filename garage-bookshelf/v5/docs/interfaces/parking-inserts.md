# 车型卡槽规范

本规范必须完全沿用[parking-tray-fit-2026-10-26](../../studies/parking-tray-fit-2026-10-26/README.md)的方法。实现细节以该目录的[build_review.py](../../studies/parking-tray-fit-2026-10-26/build_review.py)为准，原始结果见[validation.json](../../studies/parking-tray-fit-2026-10-26/validation.json)。不得用其他车型试件的流程替代本方法。

通用底脚接口标识为`parking-base-v1`。主体车位凹槽归主体；可取放底脚、取放耳及其车型固定结构归`parking-inserts`。原试件只有底脚和取放耳，不含车型轮胎夹，原结果也未证明实车固定效果。

## 通用接口必须保持

从正式总装的`parking_tray_interface_Body`取得底脚，保留其接口、装配坐标和取放耳；底脚40×80×2mm，含取放耳的通用样件包络40×83×3.2mm。单边名义间隙0.3mm，车位槽深1.6mm，层板槽底厚5mm，落座后基板高出层板0.4mm。

车型上部结构在这一接口上扩展。40×83×3.2mm描述通用样件，不要求加了车型结构后的总高仍为3.2mm；最终车型结构、车身净空及取放路径必须另行验证。不能为了适配车型改动通用底脚接口或取放耳。

## 严格沿用试件的建模与几何检查

1. 只读打开当前正式CAD，直接复制`garage_deck_2_Body`的真实层板与通用底脚，不保存或重建正式主体。参考层板为301–303三车位，195.6×158.6×6.6mm。
2. 检查CAD有效且各为单实体；用`LinearDeflection=0.02`、`AngularDeflection=0.12`、`Relative=False`导出网格。重开网格，检查封闭、无非流形、单连通；与源几何的各方向尺寸误差小于0.002mm，体积相对误差小于0.001（0.1%）。
3. 在三个车位分别检查落座与取出：先原位落座；抬高1.8mm；保持抬高后依次前移10、45、90mm。每个位置与真实层板的交集体积小于0.001mm³。
4. 按脚本以0.01mm轻微下探测量承托面积，等效接触面积大于3000mm²。保存各车位的路径、干涉量和承托检查；装配预览显示302号位落座状态。
5. 新车型必须把最终车型托座作为上述流程中的被测件；保留通用底脚与参考的接口比较，并检查最终上部结构的实际尺寸。脚本默认只验证通用样件，直接运行原脚本不能代替最终车型件验证。

## 严格沿用试配排盘与打印检查

试配项目为一盘、两个独立对象：真实三车位层板一件＋被测托座一件。两者分别底面贴床，槽口及取放凸起朝上；禁止缩放，保留脚本的排盘与尺寸检查。对象边界至少相距8mm，脚本以10mm目标间距为两个4mm brim留空间。

打印设置固定为Bambu Lab X2D、0.4mm喷嘴、黑色PLA、纹理PEI、0.20mm层高、4圈墙、25%填充、4mm自动brim、无支撑。图案使用实体凹刻，试配项目不把CAD填色或三色外观面导出成多色耗材。

保存3MF后必须独立重新加载并离线切片，不以导出成功代替检查：一盘、两对象、无模型警告、无耗材切换、单一耗材且有正用料量、实际层高0.20mm；重开时不覆写配置。交付3MF不含G-code。

## 车型制作与实物确认

新增车型源文件放`cad/parking-inserts/<车型>/<修订>/`；既有试件的正式源文件位置见[卡槽CAD索引](../../cad/parking-inserts/README.md)，不用复制第二份可编辑源。维护者记录实测值、测量定义和未知项，保留原生可编辑特征，在通用接口上设计车型固定结构。

先按本页完成最终车型托座的两对象试配项目，再交由组装者确认卡槽落座、抬出、车辆放入与取出、固定效果和车身净空。车辆接触面的设计还需要实际车模反馈；通用接口验证不能代替轮胎与车身验证。

每款保存源CAD与输出哈希、网格检查、三个槽的落座和抬出路径、承托检查、保存3MF的实际排盘、重开切片设置与结果、装配和排盘预览，并明确是否已实物试配。生成目录必须是新的`build/`子目录，不能覆盖原研究证据或正式主体。

通用流程复现（在`v5/`运行，运行名须未使用）：

```sh
/Applications/FreeCAD.app/Contents/Resources/bin/python studies/parking-tray-fit-2026-10-26/build_review.py --output build/interface-fit-r1
```

车型验证入口应复用同样的检查方法，替换被测托座后重新运行全部检查；原研究的历史结果保持原样。确认后的车型单件3MF放`printing/parking-inserts/<车型>/<修订>/`，试配项目及完整证据也应能从该款说明中找到。

现有MX-5、BMW Z4 E89的旧试件尚缺这套最终件两对象试配记录；保留其原始状态，不能因目录迁移直接标为符合新规范。
