# 生成 FreeCAD 装配检查文件

安装 FreeCAD 后，在“终端”执行以下命令：

```bash
/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd \
  /Users/kai.han/code/3d-designs/garage-bookshelf/bambu-print/generate-freecad-assembly.py
```

执行成功后，会在同一目录生成：

```text
garage-bookshelf-v4-装配检查.FCStd
```

在 FreeCAD 中打开该文件即可检查装配。左侧树状列表按底板、背板、竖板、停车场、广告牌和
右侧标牌分组；点击每组前的眼睛图标可以逐组隐藏，检查榫接、拼缝与干涉。
