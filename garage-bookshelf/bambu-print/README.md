# 车库书架 — 拓竹 X2D 打印套件

这是 920 mm「车库书架 v4」的可打印拆件版本，全部尺寸单位为毫米。
本套件针对拓竹 X2D（0.4 mm 喷嘴、256 × 256 × 261 mm 成型空间）排版，
不是将 920 mm 书架作为单件打印。

## 文件

- `garage-bookshelf-v4-x2d-pla.3mf`：已写入 X2D 与 PLA 基础预设的拓竹项目。
- `stl/`：每一个独立零件，可按需要重新分盘或分配颜色。
- `generate-models.mjs`：可复现的模型生成源文件。

## 外观试打颜色建议

| 零件 | 建议耗材颜色 |
| --- | --- |
| 底板、背板、中隔板、右侧板、停车层板、连接片、加强肋 | 灰色 PLA |
| 四根停车场立柱 | 黄色 PLA |
| 广告牌与两根广告牌柱 | 黑色 PLA |
| 右侧竖牌 | 蓝色 PLA |
| “Lovely Car I've Driven” 与 “BOOK DEPOT” 文字件 | 白色 PLA |

广告牌文字为 “Lovely Car I've Driven”，右侧竖牌文字为 “BOOK DEPOT”。本版先以 PLA
验证整体外观与装配关系；不包含书籍和车模。

## 组装

1. 所有面板平放打印；四根直径 12 mm 的立柱竖直打印，并启用 8 mm 裙边。
2. 将四段底板沿拼图榫接缝胶粘，放在水平平面上压紧固化。
3. 将八块背板拼成 920 × 300 的完整背板；在背面覆盖并胶粘所有连接片。
4. 将背板粘到底板。中隔板底部榫舌插入 `01_base_02` 的 6.2 mm 宽、4 mm 深槽；
   右侧板底部榫舌插入 `01_base_04` 的边缘台阶。两块竖板后缘连续胶粘至背板，
   再将上半块竖板与背面连接片胶粘。
5. 每层停车层板先在中部粘接，再粘至背板与前方立柱；将四个三角加强肋粘在两块
   竖板底部内侧。
6. 广告牌在背面用连接片拼接，两根广告牌柱粘到背板；右侧 “BOOK DEPOT” 竖牌粘到右侧板
   外缘。将白色 PLA 文字件分别粘在黑色广告牌和蓝色竖牌正面。

## X2D + PLA 试打参数

- 预设：拓竹 X2D 0.4 mm 喷嘴，拓竹 PLA 基础预设。
- 层高：0.20 mm；墙数：4；填充：25% 三角或陀螺填充。
- 所有面板无需支撑；仅立柱使用裙边。
- 先不要承载重书或贵重车模：PLA 试打用于确认尺寸、外观和拼装逻辑。
- 胶水可先用少量瞬干胶定位；确认外观后再决定是否用环氧胶进行永久结构粘接。

这是一份可打印概念样机，并非通过承载认证的家具。正式用于重书和收藏车模前，
应先逐步加重测试，确认每条粘接缝都已充分固化。
