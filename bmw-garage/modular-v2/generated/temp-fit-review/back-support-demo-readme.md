# 背面支撑台阶小样

文件：`Back-Support-Ledge-Demo-TEMP.3mf`

全部白色，单盘，3个短小对象：

1. `short removable sign with two pegs`：短招牌，带两个插脚。
2. `short receiver with continuous back support ledge`：短插孔梁，带连续背面支撑台阶。
3. `one-piece side cutaway showing ledge contact`：一体剖面示意件，用来直观看“招牌背面压在台阶上”；已做成自支撑形状，避免长悬臂。

用途：主要观察背面支撑台阶结构，不是最终门头生产件。插孔使用 0.20 mm 单边间隙。插孔梁为了让台阶容易看清，采用正面朝上打印方向；实际整车库门头还需要按真实方向重新测试。

打印后把短招牌插到短插孔梁上，看招牌面板是否被连续台阶托住，而不是只靠两个插脚扶正。
