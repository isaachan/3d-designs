# 三层车库 · CAD v2

本版对应已确认的[三层交替半旋坡道概念](../concepts/02-alternating-half-turn/README.md)。

- [FreeCAD 总装](cad/parking-lot-v2-assembly.FCStd)
- [STEP 交换文件](cad/parking-lot-v2-assembly.step)
- [几何和回读检查](cad/validation.json)
- [坡道支柱俯视图](cad/support-top-view.png)

总装中的三块停车板和十二个柱段及柱帽直接复制自 Garage Bookshelf v5 的原生实体。每块板为 195.6 × 158.6 × 6.6 mm，层距为 63 mm。总装保存原车位凹槽、标线和逐面配色。

右坡道从一层右前升到二层右后，左坡道从二层左前升到三层左后。每段净宽 34 mm，包含原生截面、三个放样和合并后的连续路面与护栏实体。坡道与停车板采用齐平端面对接。

2026-11-09 将两根坡道支柱各向外移 22.44 mm。立柱连同柱脚均在坡道投影之外，柱脚边缘与最外侧护栏相距 3 mm，为同一走向的上层坡道保留竖向柱线。支柱以 12 mm 宽的托臂从下方承托坡道，托臂顶面贴合坡底。接头和紧固方式留到制造设计阶段。

FreeCAD 和 STEP 均已重开验证，共 19 个闭合实体。四处接点同高，右、左坡道与车库原柱的最小净距分别为 2.25 和 5.36 mm。对照外移前的总装，原版层板、柱件和两段坡道的 17 个实体均通过几何比对。FreeCAD 文件的逐面配色也在重开后核对。

在 FreeCAD 的 Python 控制台导入本目录的 `build.py` 后，运行 `build.run('/你的路径/新输出目录')` 可复现文件。
